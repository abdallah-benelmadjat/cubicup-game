How to Play

1 Overview

CubiCup is a 2-player strategy game played on a tetrahedral pyramid. Be the player who places the final cube at the top peak.

2 Setup

  • Each player picks a color (Yellow or Blue).
  • The board starts empty. Yellow always goes first.
  • Each player has cubes equal to half the pyramid's positions.

3 Building CubiCups

  • A CubiCup forms when 3 cubes of the same color support an empty slot.
  • When you create a CubiCup, your opponent must fill it before their turn.
  • Chains can form — opponent's fill may create more cups for you!

4 Placement Rules

  • You can place on any base layer position freely.
  • Higher positions require all 3 supports below to be occupied.
  • Red ghost cubes show mandatory fills. Translucent = free moves.

5 Winning

  • Placing the peak cube (0,0,0) wins the game.
  • If all 3 peak supports are opponent's color, it's a draw.
  • Run out of cubes? Your opponent plays alone until the peak is placed.

6 Wild Mode Abilities

  • ⏭ Skip Turn (2 pts) — Force your opponent to skip their turn.
  • ⏪ Rewind 2 (3 pts) — Undo the last 2 cube placements.
  • 💥 Destroy Cube (4 pts) — Click to remove any opponent leaf cube.
  • 🎭 Control Opp. (5 pts) — Place one cube AS your opponent.
  • Earn 1 point every time you create a CubiCup on a free move!

7 Tips

  • Creating 2 CubiCups in one move forces a guaranteed win chain.
  • Control the 3 peak support positions: (1,0,0), (0,1,0), (0,0,1).
  • In Wild Mode, hoard points and use abilities at critical moments.

const { io } = require('socket.io-client'); const socket = io('https://cubicup.abe-ben.dev'); socket.on('connect', () => { socket.emit('bot-register', { name: 'MyBot' }); socket.emit('create-bot-room', { opponent: 'ai:hard' }); }); socket.on('game-start', data => { if (data.state.your_turn) makeMove(data.state); }); socket.on('opponent-move', data => { if (data.game_over) return; if (data.state.your_turn) makeMove(data.state); }); function makeMove(state) { const move = state.legal_moves[Math.floor(Math.random()*state.legal_moves.length)]; socket.emit('move', { move }); }
